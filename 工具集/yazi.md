# yazi

终端里的 Finder，全程键盘操作。三栏布局：左边是上级目录，中间是当前目录，右边实时预览光标所在的文件（文本、代码、图片、PDF）。

适合：找文件、边翻边预览、整理文件。
不适合：跳到已知目录（直接 `cd` 更快）。

## 安装与配置

### 1. 安装

```sh
# 必需：yazi 本体 + fd（按文件名搜索用）
brew install yazi fd

# 可选：预览视频、压缩包、PDF、图片
brew install ffmpeg sevenzip poppler imagemagick
```

按内容搜索（`S`）依赖 `rg`，跳目录依赖 `fzf` 和 `zoxide`，没装的话一起装：`brew install ripgrep fzf zoxide`。

### 2. 添加 `y` 启动命令

加到 `~/.zshrc` 末尾，然后 `source ~/.zshrc`：

```sh
# yazi：用 y 启动，退出（q）时终端切到最后浏览的目录，Q 退出则留在原地
function y() {
  local tmp="$(mktemp -t "yazi-cwd.XXXXXX")" cwd
  yazi "$@" --cwd-file="$tmp"
  IFS= read -r -d '' cwd < "$tmp"
  [ -n "$cwd" ] && [ "$cwd" != "$PWD" ] && builtin cd -- "$cwd"
  rm -f -- "$tmp"
}
```

直接运行 `yazi` 也能用，但退出后终端会回到原来的目录；用 `y` 启动，退出时终端会停在你最后浏览的目录。

### 3. 默认显示隐藏文件

新建 `~/.config/yazi/yazi.toml`：

```toml
# 默认显示隐藏文件（.claude、.config 等），按 . 仍可临时切换
[mgr]
show_hidden = true
```

不配置的话 `.claude` 这类目录默认看不到，也搜不到。

## 常用快捷键

### 浏览

| 按键 | 作用 |
|---|---|
| 方向键 / `h` `j` `k` `l` | 左：上级目录；下/上：移动光标；右：进入目录 |
| `J` / `K` | 预览区向下 / 向上滚动 |
| `Enter` / `o` | 打开文件（只是想看内容的话不用按，右栏就是预览） |
| `.` | 显示或隐藏隐藏文件 |

### 找文件

| 按键 | 作用 |
|---|---|
| `f` | 过滤当前目录，只显示名字匹配的文件 |
| `/` | 在当前目录查找，`n` / `N` 跳到下一个 / 上一个 |
| `s` | 递归搜索子目录里的文件**名** |
| `S` | 递归搜索子目录里的文件**内容** |
| `Z` | 用 zoxide 跳到常去的目录 |
| `z` | 用 fzf 模糊搜索文件或目录并跳过去 |
| `g` 然后空格 | 直接输入路径跳转，比如 `~/.claude` |
| `Esc` | 取消过滤、搜索或选择 |

搜索只匹配文件名，不匹配路径：搜 `claude`，不要搜 `~/.claude`。搜索范围是当前目录，先进到大概的位置再搜，速度更快。

### 文件操作

| 按键 | 作用 |
|---|---|
| `空格` | 选中或取消选中（可以连续选多个） |
| `y` / `x` | 复制 / 剪切 |
| `p` | 粘贴 |
| `d` | 移到废纸篓 |
| `a` | 新建文件；名字以 `/` 结尾就是新建目录 |
| `r` | 重命名 |
| `c` 然后 `c` | 复制文件路径 |

### 退出

| 按键 | 作用 |
|---|---|
| `q` | 退出，终端切到当前浏览的目录 |
| `Q` | 退出，终端留在原来的目录 |
| `~` | 查看全部快捷键 |

## 常见问题

- **按回车后进了 vi，出不来**：没设置 `EDITOR` 时，文本文件会用 vi 打开。先按 `Esc`，再输入 `:q` 回车；有修改但不想保存就用 `:q!`。
- **图片预览显示成色块**：终端不支持图形协议。kitty、Ghostty、iTerm2、WezTerm 都可以，macOS 自带的“终端”不行。
- **打开图片或 PDF 后弹出了别的应用**：yazi 还开着，`Cmd + Tab` 切回终端就行。
